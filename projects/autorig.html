Autorig Tool

The tool showcased in this video is an autorig coded in Python for Autodesk Maya.
It allows to create instant rigs based on the placement of clusters (or locators). It can create an Ik/Fk set-up for arms, legs, and spine, complete of spine twist. In the latest version, the arm twist was added, together with additional controls on all limbs.
Lastly, the naming convention allows for quick selection of the skinning joints.

The model used in the showcase is Amy by Gop Gap.
